Apresentação dos Entregáveis

Neste repositório estão disponíveis quatro atividades desenvolvidas em Python, com o objetivo de colocar em prática os conhecimentos adquiridos sobre lógica de programação.

Cada atividade trabalha um conceito diferente da linguagem, permitindo exercitar o raciocínio lógico e compreender melhor como funcionam as estruturas do Python.

Atividades desenvolvidas
Classificador de Cliente: um programa que recebe a idade e o rendimento do cliente e, com base nessas informações, define a sua categoria: Bronze, Prata, Ouro ou Diamante.
Menu de Operações Matemáticas: um programa que apresenta quatro opções de operações matemáticas e realiza o cálculo escolhido pelo utilizador.
Análise de Números: um programa que recebe cinco números e apresenta a soma, a média, o maior e o menor valor.
Sistema de Autenticação: um programa que simula um acesso por senha, permitindo até três tentativas antes de bloquear o acesso.
Objetivo

Com estas atividades, a ideia é desenvolver e praticar os conhecimentos em Python, principalmente o uso de condições (if, elif e else), escolhas (match/case) e estruturas de repetição (for e while).

Todos os códigos foram desenvolvidos de forma simples e com comentários para facilitar a compreensão de cada etapa.
